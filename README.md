# TIBRAP

**A Benchmark and Tool-Augmented Framework for Tibetan Multimodal Question Answering**

[Benchmark](benchmark/README.md) · [Method](method/README.md) · [Results](RESULTS.md)

## Benchmark

TIBRAP-Bench contains 1,000 Tibetan image–question pairs across four visual capabilities and four answer formats: 900 evaluation records and 100 development-visible records.

The benchmark provides questions, answers, source datasets, image filenames and record IDs. See [data preparation](benchmark/README.md#images).
